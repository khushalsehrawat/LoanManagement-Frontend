What I built

🧩

A complete LAMF LMS that supports the full journey: Product configuration → Loan Application creation → Collateral (MF units) capture → Eligibility computation (LTV) → Approval/Disbursal → Active loan tracking → Repayments.

Why it matters

🎯

LAMF products require disciplined collateral tracking. This system models mutual fund holdings as collateral and derives eligible limits using max LTV — mirroring real NBFC lending operations.

API Design

🛡️

Internal operations are secured with JWT, while partner integrations use API Key authentication.

  • /api/** (JWT) — products, applications, loans, repayments
  • /partner/v1/** (API Key) — fintech creates loan applications
